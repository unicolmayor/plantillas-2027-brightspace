Ejemplos de imágenes

Esta página contiene ejemplos de imágenes.

Buenas prácticas

Puedes añadir imágenes a tus páginas para hacerlas más atractivas y dividir bloques extensos de texto. Esta sección muestra distintas formas de utilizarlas.

Puedes realizar una de las siguientes acciones:

  • Reemplazar las imágenes y el texto de esta página
  • Seguir las instrucciones de abajo para insertar imágenes en otras páginas
  • Copiar los ejemplos de alineación de imágenes de esta página y pegarlos en otras páginas

Reemplazar una imagen

Esta plantilla incluye algunas imágenes de ejemplo. Para reemplazar una imagen:

  1. Selecciona la imagen y elimínala (Nota: No muevas el cursor)
  2. Haz clic en el icono Insertar imagen
  3. Selecciona el origen de la imagen
  4. Haz clic en el botón Elegir destino para guardarla en la carpeta que quieras

Tamaño recomendado para el banner: al menos 1200 píxeles de ancho por 400 píxeles de alto.

Insertar una imagen nueva

Insertar una imagen propia es sencillo. En el modo «Editar HTML», utiliza Insertar imagen. Si la imagen no tiene el tamaño adecuado, puedes ajustarla con el editor de imágenes integrado.

Alineación de imágenes

El editor HTML permite usar las opciones Alinear a la izquierda, Alinear a la derecha y Alinear a todo el ancho para ubicar una imagen.

Por ejemplo, si quieres que la imagen aparezca a la izquierda y el texto la rodee:

  1. Inserta la imagen en la línea vacía antes del párrafo
  2. Recorta la imagen o ajusta sus dimensiones al tamaño deseado
  3. Aplica Alinear a la izquierda a la imagen seleccionada

Copiar imágenes

Para copiar cualquiera de las siguientes imágenes, selecciona todo el contenido entre «inicio de copia» y «fin de copia» de la imagen correspondiente. Luego, cópialo y pégalo en el editor HTML.

Para copiar imágenes en otra página, asegúrate de que esté en modo «Edición».
