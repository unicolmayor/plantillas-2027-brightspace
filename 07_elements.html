Elementos de página

Esta página contiene ejemplos de elementos de uso frecuente.

Puedes copiar uno o varios elementos de esta página y pegarlos en otras páginas. Al combinarlos, puedes crear nuevas disposiciones para tus cursos.

Copiar elementos

Para copiar cualquiera de los siguientes elementos, selecciona todo el contenido entre «inicio de copia» y «fin de copia» del elemento correspondiente. Luego, cópialo y pégalo en el editor HTML.

Para copiar elementos en otra página, asegúrate de que esté en modo «Edición».
